🚦 并发与限速

同时进行的下载任务越多总速度越快，但太激进容易触发站点风控（被冷却反而更慢）；限速适合「下载时还想玩游戏/开会」的场景。
MB/s（0=不限）
调小并发立即生效；调大立即补位启动排队任务 · 限速对视频下载（yt-dlp / 直连引擎）生效；图文站（gallery-dl）走请求间隔保护，不限速

🔑 Cookie 管理 多站点通用

B 站登录后自动写入。其他站点（YouTube / Pixiv / X / Instagram…）可用浏览器扩展 Get cookies.txt LOCALLY 登录后导出 Netscape 格式 cookies.txt，在此导入——下载时会自动带上对应站点的登录态（更高清晰度、更少风控）。Cookie 只存本机。
（暂无，B 站登录后自动出现 bilibili.com）
选了浏览器后下载与订阅检查直接带该浏览器的登录态，免手动导出 cookies.txt（需浏览器已登录目标站点；Chrome 新版部分站点可能加密读不到，读不到时再回落手动导入）。改完即时生效。注意：该浏览器正在运行时 Windows 会锁定 Cookie 文件导致读取失败——请先完全退出它再下载/订阅。

💾 数据安全 换机搬家

MB 剩余空间
下载目录所在盘剩余空间低于该值时任务自动暂停（清理空间后自动续跑）；设为 0 关闭检测
导出 = 一份 JSON 文件（含全部设置 + 订阅清单及跟踪进度 + AI 配置）；导入 = 设置覆盖恢复、订阅按链接合并不重复。不含 Cookie（换机请重新登录）与媒体文件本体（拷下载目录即可）

✨ AI 文稿助理 BYOK 自备 Key

对已转写的文字稿跑 AI 摘要 / 翻译。填任意 OpenAI 兼容接口（OpenAI / DeepSeek / 硅基流动 / Ollama / LM Studio 均可）。Key 只存本机 settings.json，不经任何第三方。媒体库文件点 ✨ 即可使用，结果存为同名 .ai.md。

⬆️ 软件更新

手动点「检查更新」；新版发布后每天启动时也会自动提醒（任务队列空闲时才装，不会打断下载）。更新源是一个 JSON 地址，格式：{"version":"0.2.0","url":"新版安装包下载地址"}
