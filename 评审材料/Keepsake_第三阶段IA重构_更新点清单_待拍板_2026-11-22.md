# Keepsake 第三阶段 IA 重构 — 更新点清单（待拍板 · 2026-11-22）

> 回应「不还是换了个皮肤么？为什么不能就按设计图来做」——根因：设计图只画了一个视图（媒体库），没画任务/订阅/设置页。这次动的是**信息架构**，不是刷漆。

## 改了什么（commit `442a4b0`，本地未 push）

### 1. 启动默认页 = 媒体库
- 以前启动第一眼是任务队列页（旧版观感的主要来源）；现在启动直接进设计图的主视图：卡墙 + 分段控件 + 侧栏订阅列表。

### 2. 侧栏按设计图重排（设计图结构）
- **媒体库组**：媒体库（默认高亮）+ **手动添加**入口（点击 → 媒体库手动视图并高亮）
- **订阅主页**：动态列表，随订阅增删实时同步；点击订阅 → 媒体库按该订阅名过滤出 TA 的全部归档；检查失败的订阅显示红点；超过 8 个折叠成「＋其余 N 个订阅…」
- **工具组**：订阅归档、任务队列、限流策略、小红书、设置收在下方

### 3. 订阅页卡片化
- 旧版一行卡糊着「检查频率/最近成功/最近失败/连续失败/回溯上限/关键词…」十几段长串 → 新卡片：图标 + 名称 + 平台徽标 + 短状态行，长串收进「调度与规则」展开区（**信息一条不丢**，点开就能看）
- 操作按钮（🔗⟳⤓📂🏷⚙▶✕）整排右对齐，悬停高亮

### 4. 口径统一
- 「手动保存」全部改口「手动添加」（9 处）——与设计图及缺口①的原始说法一致

## 为什么这样切
- 任务队列页的行卡/进度条在第一阶段 CSS 全量重写时已套融合版变量，视觉已是新体系；这轮把「组织方式」换掉后，整体才真正是设计图的骨架。
